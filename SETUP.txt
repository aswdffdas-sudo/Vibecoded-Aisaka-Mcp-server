================================================================================
          AISAKA 2021 ROBLOX STUDIO MCP BRIDGE - SETUP GUIDE
================================================================================

This project connects AI tools (OpenCode, Claude Desktop, Cursor, Codex, 
Windsurf, Claude Code) directly to 2021 Roblox Studio / Aisaka Studio using 
Anthropic's Model Context Protocol (MCP).

--------------------------------------------------------------------------------
STEP 1: INSTALL THE STUDIO PLUGIN
--------------------------------------------------------------------------------
1. Press [Windows Key + R] on your keyboard to open the Run dialog.
2. Type or paste this and click OK:
   %localappdata%\Roblox\Plugins

3. Copy the file "MCPBridge2021.lua" from this folder into that Plugins folder.
4. Launch your 2021 Roblox Studio and open your place.
5. Make sure HTTP requests are enabled:
   - In Studio: Go to Game Settings -> Security -> Turn ON "Allow HTTP Requests"
   - OR paste this into the Studio Command Bar at the bottom and press Enter:
     game:GetService("HttpService").HttpEnabled = true

6. In Studio's Output window, you should see:
   [MCP 2021] Bridge initialized. Connecting to http://127.0.0.1:3021 ...


--------------------------------------------------------------------------------
STEP 2: INSTALL SERVER DEPENDENCIES
--------------------------------------------------------------------------------
1. Make sure you have Node.js installed (https://nodejs.org).
2. Open Command Prompt or PowerShell in this folder.
3. Run this command:
   npm install


--------------------------------------------------------------------------------
STEP 3: CONFIGURE YOUR AI CLIENT
--------------------------------------------------------------------------------

A) FOR OPENCODE:
Add to your opencode.json or ~/.config/opencode/opencode.jsonc:

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "Roblox_2021": {
      "type": "local",
      "command": ["node", "C:/path/to/server.js"],
      "enabled": true
    }
  }
}


B) FOR CLAUDE DESKTOP:
Open %APPDATA%\Claude\claude_desktop_config.json and add:

{
  "mcpServers": {
    "roblox-2021": {
      "command": "node",
      "args": ["C:/path/to/server.js"]
    }
  }
}


C) FOR CURSOR:
Create .cursor/mcp.json in your workspace (or via Settings -> Features -> MCP):

{
  "mcpServers": {
    "roblox-2021": {
      "command": "node",
      "args": ["C:/path/to/server.js"]
    }
  }
}


D) FOR CODEX CLI:
Run in your terminal:
codex mcp add roblox-2021 -- node "C:/path/to/server.js"


E) FOR WINDSURF:
Open ~/.codeium/windsurf/mcp_config.json and add:

{
  "mcpServers": {
    "roblox-2021": {
      "command": "node",
      "args": ["C:/path/to/server.js"]
    }
  }
}


F) FOR CLAUDE CODE CLI:
Run in your terminal:
claude mcp add roblox-2021 -- node "C:/path/to/server.js"


--------------------------------------------------------------------------------
AVAILABLE TOOLS EXPOSED TO THE AI
--------------------------------------------------------------------------------
- screen_capture: Captures a screenshot of the Studio window/viewport for the AI.
- execute_luau: Runs Luau/Lua code directly inside 2021 Studio edit mode.
- get_tree: Inspects game hierarchy and objects in Workspace, StarterGui, etc.
- read_script: Reads the complete source code of any script in your game.
- write_script: Edits or overwrites script source code.
- create_instance: Creates parts, models, GUIs, or scripts.
- delete_instance: Removes instances from the game.
- get_output_log: Reads the Studio console output history.
- script_grep: Global regex/text search across all scripts in the game.
- inspect_instance: Inspects detailed properties, attributes, and tags of any object.
- audit_scene_assets: Scans all 3D scene objects (sounds, meshes, decals, particles) for asset IDs.
- start_playtest: Starts Play Solo (F5) or Run (F8).
- stop_playtest: Stops playtest and returns to Edit mode (Shift+F5).
- run_playtest: Autonomous AI test run: tests game, captures errors & screenshot, stops cleanly.
